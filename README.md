# 📊 Amazon Sales Analysis – Power BI Dashboard

## 📌 Project Overview

This project presents an interactive Amazon Sales Analysis Dashboard created using Microsoft Power BI.

The dashboard analyzes sales performance, revenue trends, product performance, and other key business metrics to generate meaningful insights from the dataset.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization
- Business Intelligence

## 📊 Dashboard Features

- Total Sales analysis
- Sales performance KPIs
- Product-wise analysis
- Category-wise analysis
- Sales trend analysis
- Interactive filters and slicers
- Charts and visualizations
- Business insights

## 🔄 Data Preparation

The dataset was prepared using Power Query.

The data preparation process included:

- Removing unnecessary data
- Handling missing values
- Correcting data types
- Cleaning and transforming columns
- Preparing data for analysis

## 📈 Analysis

The Power BI dashboard provides insights into:

- Overall sales performance
- Product performance
- Category performance
- Sales trends
- Key business metrics
